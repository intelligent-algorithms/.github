# Intelligent Algorithms Ltd

Applied optimisation, machine learning, and quantitative research consultancy.

[intelligent-algorithms.co.uk](https://intelligent-algorithms.co.uk)

## About

A research and engineering consultancy combining peer-reviewed optimisation work with production machine learning experience in fintech, environmental monitoring, and applied analytics.

Public repositories on this organisation account host reference implementations, teaching material, and the source for the company website. The bulk of working code is private or held with clients.

## Active areas

- **Optimisation** — combinatorial optimisation, metaheuristics (tabu search, tabu thresholding, surrogate constraints), constraint handling.
- **Applied ML** — explainable financial sentiment with transformer language models, anomaly detection for market data, time-series forecasting.


## Background

Peer-reviewed work in adaptive metaheuristics, published in *Annals of Operations Research* and in the Springer *Meta-Heuristics* volume.
